# Accessibility

Uwaci assumes users may have limited literacy, low vision, motor constraints, or screen-reader use. The microphone uses a 112-point primary target with a descriptive label, hint, busy state, and text status. Other controls meet a 48-point minimum. Roles, selected states, alert/live regions, readable labels, and logical focus order are baseline requirements.

No critical state is color-only: recording, processing, failure, and experimental language status include text. Typography targets comfortable line height and contrast. Conversation lists identify speaker roles; playback controls say what they do. Copy stays direct and avoids technical provider language.

Review Android TalkBack, font scaling, keyboard navigation where relevant, reduced motion, contrast, and one-handed operation before each user-facing PR. Voice-first does not mean voice-only: every core action needs a text path.
